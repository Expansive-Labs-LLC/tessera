# Keyboard Shortcuts

Tessera uses Blender's built-in keyboard shortcuts. No custom shortcuts are defined — all interactions use standard Blender keys.

---

## Essential Blender Shortcuts

## Navigation

### ++n++ — Toggle Sidebar

Shows or hides the 3D Viewport sidebar where all Tessera panels are located.

### ++tab++ — Toggle Edit Mode

Switches between Object Mode and Edit Mode for manual mesh editing.

### ++z++ — Shading Pie Menu

Access different viewport shading modes (Solid, Material Preview, Wireframe, Rendered).

---

## Editing

### ++ctrl+z++ — Undo

Reverts the last operation. Works for Tessera refinement commands too.

### ++ctrl+shift+z++ — Redo

Re-applies an undone operation. Restores the last undone change.

### ++f++ — Fill Face

In Edit Mode, creates a face from selected edges or vertices. Useful for manually filling holes.

### ++m++ — Merge Vertices

In Edit Mode, merges selected vertices. Useful for fixing duplicate vertices manually.

---

## Selection

### ++a++ — Select All

Selects all objects in Object Mode or all elements in Edit Mode.

### ++alt+a++ — Deselect All

Deselects all objects or elements.

### ++l++ — Select Linked

In Edit Mode, selects all elements connected to the element under the cursor.

---

## View

### ++numpad-0++ — Camera View

Switches to the active camera view.

### ++numpad-5++ — Toggle Perspective/Orthographic

Switches between perspective and orthographic projection.

### ++numpad-period++ — Focus Selected

Centers the viewport on the selected object.
